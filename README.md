# Neo.do Manage all of your todos

### Run This project locally -
#### Clone this repo into a directory
```shell
git clone https://github.com/prathameshrp/todo-list.git
```
#### Install all the required packages:
```shell
npm install
```
#### Start the development build
```shell
npm run dev
```

### Contribution guide - 
- Before starting to work on an issue, make sure to raise the issue on the main github repository
- Then wait for the maintainer to assign the issue to you.
- Once the issue is assigned to you, you can start working on it.

> All of the project structure code is in `src` directory.

> All the assets like images/icons/fonts goes in `assets` directory in appropriate subdirectory

> `dist` is for webpack output and contains production code

To contribute your work -

- [x] Fork the repository
- [x] Clone it in your local environment (make sure you pull all the latest changes to avoid merge conflicts) and start working with it.
- [x] Once you are ready with your fix/feature commit and push the code to your remote fork
- [x] Make a Pull Request

# Things to consider while making a PR:
  - Make sure your PR explains the problem statement and reference the relevant issue if any.
  - Attach before and after screenshots if applicable
  - Be patient and wait for a maintainer to approve and accept your PR
